# @botyard/ui

React pieces for [Botyard](https://botyard.io) Bot Pages, part of
[create-botyard-app](https://github.com/Botyard-AI/create-botyard-app).

**Not ready yet.** The published `0.0.x` versions are placeholders: importing
them throws a "not ready yet" error. Watch
[the repository](https://github.com/Botyard-AI/create-botyard-app) for the
first real release.
